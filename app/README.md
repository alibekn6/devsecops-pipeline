# app

A minimal FastAPI service that the DevSecOps pipeline in this repository builds, tests, and scans.
The service stays small on purpose: the pipeline around it is the subject of the project.

## Stack

| Component | Version |
|-----------|---------|
| Python | 3.13 |
| FastAPI | 0.163.0 |
| Uvicorn | 0.54.0 |
| uv (package manager) | 0.12.23 |
| pytest | 9.2.0 |

Exact dependency versions are pinned in `uv.lock`.

## API

| Method | Path | Response |
|--------|------|----------|
| `GET` | `/health` | `200 {"status": "ok"}` |
| `GET` | `/docs` | Swagger UI generated by FastAPI |

## Run locally

Requires [uv](https://docs.astral.sh/uv/). It installs the right Python version automatically.

```bash
cd app
uv sync
uv run uvicorn app.main:app --reload
```

The service listens on <http://127.0.0.1:8000>. Check it with:

```bash
curl http://127.0.0.1:8000/health
```

## Run tests

```bash
cd app
uv run pytest -v
```

CI runs the same command with `uv sync --locked`, so a test run fails if `uv.lock` is out of date with `pyproject.toml`.

## Docker

Build and run the image:

```bash
cd app
docker build -t app:local .
docker run --rm -p 8000:8000 app:local
```

Image design:

- **Multi-stage build.** The builder stage installs dependencies with uv. The runtime stage copies only the ready `.venv`, so neither uv nor build caches end up in the final image.
- **Layer caching.** Dependencies are installed before the source code is copied, so a code change does not reinstall dependencies.
- **Non-root user.** The container runs as `app` (UID/GID 10001) with no login shell.
- **Health check.** Docker probes `/health` every 30 seconds using the Python standard library, so the image needs no `curl`.
- **Small build context.** `.dockerignore` excludes `.git`, `.venv`, caches, and `.env` files, so local secrets cannot leak into the image.
